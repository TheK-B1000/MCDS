# Primary research sources

The implementation was verified against four primary papers. See
`docs/source_audit.md` and `docs/algorithms/`.

Local PDFs are stored under `papers/primary/` and are **not committed**.
Redistribution rights vary by publisher. Bibliographic metadata and SHA-256
hashes below are version-controlled so a later checkout can confirm it is
using the same documents.

Hashes are SHA-256 of the exact files used in the 2026-10-05 paper-to-code
audit (`main` @ `06bf246` at the time of that check).
